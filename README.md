# 基金分析報告產生器

## 啟動

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## 輸入資料

- 淨值檔：`日期、基金、淨值、基金規模（選填）`
- 持股檔：`日期、基金、代碼、持股、權重、產業、投資題材、區間報酬`

持股檔至少需要兩個揭露日期，才能計算新進、出清、加碼與減碼。權重與區間報酬均使用百分點，例如 `5.25` 代表 `5.25%`。

目前版本以使用者上傳或公開月報整理資料為主。若要自動串接投信官網、MoneyDJ或其他平台，應先確認授權、頁面結構及更新頻率。

## 網址分析

選擇「網址分析」後，可貼上公開基金頁面、CSV 或 Excel 連結。系統會嘗試辨識淨值及持股表格；也可以分別提供淨值與持股網址。登入頁面、驗證碼、封鎖機器人或必須執行 JavaScript 才顯示的資料無法直接讀取，需改用檔案上傳。
