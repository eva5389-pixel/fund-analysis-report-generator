# 基金分析報告產生器

## 啟動

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## 輸入資料

- 淨值檔：`日期、基金、淨值、基金規模（選填）`
- 持股檔：`日期、基金、代碼、持股、權重、產業、投資題材、區間報酬`

持股檔至少需要兩個揭露日期，才能計算新進、出清、加碼與減碼。權重與區間報酬均使用百分點，例如 `5.25` 代表 `5.25%`。

目前版本以使用者上傳或公開月報整理資料為主。若要自動串接投信官網、MoneyDJ或其他平台，應先確認授權、頁面結構及更新頻率。

## 網址分析

選擇「網址分析」後，可貼上公開基金頁面、CSV 或 Excel 連結。系統會嘗試辨識淨值及持股表格；也可以分別提供淨值與持股網址。登入頁面、驗證碼、封鎖機器人或必須執行 JavaScript 才顯示的資料無法直接讀取，需改用檔案上傳。

## 績效題材與匯率比較

首頁新增比較模式；可切回「原有基金深度分析」。比較模式支援 2–10 檔基金、CSV/Excel 多檔上傳，或原有 MoneyDJ ACPS 網址匯入。持股題材檔選填；未提供不阻擋績效比較。

- 使用各基金共同有淨值的起訖日。
- 同時輸出原幣、台幣、美元報酬，以及匯率影響百分點。
- 匯率目前由使用者輸入或上傳，統一為一單位外幣兌台幣，必須是共同起訖日資料；不自動下載或補值。
- 確認級別幣別及含息口徑，避險級別不再重複扣除基金內部避險。
- 題材採期末以前最近一期資料，保留未揭露權重並提示資料過舊。
- 完整比較報告輸出 HTML（瀏覽器列印可存 PDF），另有績效及題材 CSV。原功能的 Word 報告保留。
- 示範資料為模擬，不代表真實市場行情。

驗證：`python -m unittest discover -s tests -v`。
